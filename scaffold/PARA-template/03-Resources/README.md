# 📚 03-Resources — ความรู้/แหล่งอ้างอิง

> **ความรู้ ความสนใจ ความอยากรู้** — แชร์เป็น public ได้

## ตัวอย่าง

- `Books/` — หนังสือและบันทึกสรุป
- `Templates/` — แม่แบบเอกสาร
- คู่มือ, cheat sheet, note การเรียน, reference

## กติกา

- Resource = แหล่งความรู้ (private ได้ แต่ public ได้ด้วย)
- ไม่ใช่ "บทบาทหน้าที่" (นั่นคือ Area)
- อัปเดต/เพิ่มได้เรื่อย ๆ — ไม่มีวัน "จบ"
