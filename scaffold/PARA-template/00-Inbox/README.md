# 📥 00-Inbox — กล่องจดหมาย

> **ทุกอย่างที่ยังไม่ได้จัดเรียง** — ของดิบที่เพิ่ง capture เข้ามา

## กติกา

- ไฟล์ทุกชนิดที่ยังตัดสินใจไม่ได้ → วางที่นี่ก่อน
- เปลี่ยนชื่อให้สื่อความหมาย (อย่าใช้ชื่อ default เช่น `Untitled`)
- จัดเรียงตามคำถาม PARA:
  1. เกี่ยวกับโปรเจกต์ที่กำลังทำไหม? → `01-Projects/`
  2. ช่วยในความรับผิดชอบระยะยาวไหม? → `02-Areas/`
  3. เป็นความรู้/ความสนใจไหม? → `03-Resources/`
  4. ยังไม่ต้องการแต่เก็บไว้? → `04-Archives/`
- ตั้งเป้าให้ Inbox **ว่าง** เป็นประจำ (weekly cleanup)
