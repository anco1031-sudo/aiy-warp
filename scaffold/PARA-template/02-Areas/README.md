# 🗺️ 02-Areas — พื้นที่รับผิดชอบระยะยาว

> **มาตรฐานที่ต้องรักษาไว้** — ไม่มีวันสิ้นสุด ไม่ใช่โปรเจกต์

## ตัวอย่าง

- `Health/` — การดูแลสุขภาพ, ผลตรวจ, ติดตาม
- `Events/` — งาน/กิจกรรมที่ต้องเข้าร่วม
- `Logs/` — บันทึกประจำวัน
- การเงินส่วนตัว, ครอบครัว, การงาน

## กติกา

- Area = บทบาทหน้าที่ที่คุณเป็น (ไม่มี deadline)
- ถ้าเริ่มเป็น "โครงการที่มี deadline" → ย้ายไป `01-Projects/`
- ข้อมูลส่วนตัวส่วนใหญ่เป็น Area (private) — Resource ต่างหากที่แชร์ได้
