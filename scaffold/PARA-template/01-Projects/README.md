# 🚀 01-Projects — โปรเจกต์ที่กำลังทำ

> **ความพยายามระยะสั้นที่มีเป้าหมาย + กำหนดเวลาชัดเจน** — จบได้ และแบ่งย่อยได้

## กติกา

- หนึ่งโปรเจกต์ = หนึ่งโฟลเดอร์: `01-Projects/{ProjectName}/`
- ทุกโปรเจกต์ต้องมี: เป้าหมาย + deadline (แม้แต่ในใจ)
- deliverables ส่งมอบแล้ว + อนุมัติแล้ว → ย้ายไป `04-Archives/`
- ถ้าโปรเจกต์ไหนไม่มี deadline → จริง ๆ มันคือ Area หรือ Resource มากกว่า
